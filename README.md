# Course Management System

A full-stack Course Management System built using React and JSON Server.  
The application allows users to browse courses, view course details, manage courses, and maintain a shopping cart with user authentication and protected routes.

## 🚀 Features

- 🔐 User Signup and Login
- 🏠 Course listing and browsing
- 📚 View detailed course information
- ➕ Add new courses
- ✏️ Update existing courses
- 🛒 Add courses to cart
- 🔒 Protected routes for authenticated users
- 👤 User context and authentication management
- 📱 Responsive user interface
- 🌐 REST API using JSON Server
- ⚡ Fast development using Vite

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Nithishreejh/ReactBasedCourseManagementSystem.git
```

### 2. Navigate to the project

```bash
cd ReactBasedCourseManagementSystem
```

### 3. Install frontend dependencies

```bash
cd course-management-frontend
npm install
```

### 4. Start the frontend

```bash
npm run dev
```

The frontend will run on the Vite development server.

### 5. Start JSON Server

Open another terminal and navigate to the backend folder:

```bash
cd backend
```

Then run:

```bash
npx json-server --watch database.json
```

The JSON Server API will be available on its configured local port.
